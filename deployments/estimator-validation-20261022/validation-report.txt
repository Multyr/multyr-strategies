IMPLEMENTATION
1. Reliable per-adapter, per-direction EMA drives the estimate, even below the default. Reliability requires at least three stable execution observations, no more than seven days old. Gas below 21,000 is rejected as evidence. A >1.25x regime change or stale history resets the evidence. Legacy keeper-reported values cannot establish reliability.
2. Cold-start defaults are rounded measured maxima for each operation; a single 50% margin applies to the resulting total. Defaults are not permanent EMA floors.
3. The planner selects top composite-score adapters using the 1–2–3–4–5 TVL limits, bounded by maxAdaptersPerAllocation. Exposure caps remain independent and can leave idle capital. The estimator contains no scoring logic.
4. The shared candidate action builder supplies the gate and prepared plan. Withdrawal liquidity is clamped before funded deposit amounts are calculated. Batch count comes from the actual action list. Preparation, withdrawal-only, deposit-only, mixed steps and finalization are priced separately; finalization is not an extra transaction.
5. Remaining-plan validation rechecks prices, economics, liquidity, cash and caps, and now cancels deposits into adapters excluded by freshly computed targets. Existing expiry and TVL-drift guards remain. It does not promise an optimal trade search or continuously replace a profitable stored plan with new target weights.
6. Morpho sorts a snapshot of market APYs instead of repeatedly querying valuations inside comparisons. The original trace had 23 convertToAssets calls costing 2,018,378 gas and a failed first deposit attempt followed by a successful fallback. The optimization preserves fallback behavior.

VALIDATION SCOPE
Pinned Arbitrum state: block 516950276. Five profitable hypothetical books at 10K, 100K, 500K, 2M and 6M USDC used explicit APY overrides to exercise allocation paths. Each quote matched the prepared action list and each plan completed without failures in separate local transactions.
Five additional actual-rate replays removed the APY overrides. Four required a local economic-rejection override to measure otherwise-blocked execution; only the 100K actual-rate case originally passed the economic gate. These conditional runs are NOT profitability approvals.
70 additional local transactions cover five deposit/full-recall cycles on each of seven adapters. These include first and repeated deposits; the tier plans also exercise partial withdrawals. This is finite coverage at one block, not a worst-case gas guarantee.
The exact illustrative 500K Aave/Venus -> Morpho/Euler/Fluid case is covered by a mocked-adapter integration test: five operations, one preparation plus three execution transactions. A 40% cap override is explicit because 200K/500K exceeds the ordinary three-adapter ~36.7% cap. The real-protocol 500K fork uses a different starting book and has seven operations; do not confuse the two.

ACCOUNTING
Gross transaction gas = adapter measurements + strategy overhead + separate finalization + intrinsic/calldata. Adapter gas uses the strategy measurement boundaries. Finalization is identified from matching compiled program counters and subtracted from the last execution step. Intrinsic/calldata is 21,612 per tested upkeep wrapper. Receipt gas is gross less refunds; estimates conservatively do not credit refunds.
L2 gas is multiplied by pinned L2 price 20,118,000 wei. ETH/USD = 2505.9; USDC/USD = 0.99990035. Poster fees are added once using the existing model (164-byte allowance). The EVM fork does not execute native ArbOS poster accounting. Therefore these USDC figures are measured EVM gas priced with pinned inputs plus MODELED poster fees, not live total-fee receipts. Native Arbitrum reconciliation remains a deployment validation item.
